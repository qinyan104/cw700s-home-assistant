# Windows 本地 AI 操作速查

分类程序默认只扫描 `D:\CW700S\ObjectMotion`。它不会移动、改名或删除原始录像，结果保存在 `D:\CW700S\AI\cw700s_ai.db`；再次运行会跳过内容未变化且已成功分析的录像。

结果类别包括人物、车辆、动物、它们的组合，以及“未识别目标”。“未识别目标”只表示采样画面没有命中当前目标类别，不表示录像无用，也不是删除依据。

日常增量使用：双击 `运行CW700S_AI分类.bat`。

测试 10 条、强制 CPU、重新检查、调整置信度、修改单视频超时和生成预览，请使用 [详细指南](../docs/05-local-ai.md) 中的 Python 命令。

`--save-preview` 生成的 `D:\CW700S\AI\previews` 包含摄像头画面；发布前必须遮盖可识别的人员、住址和其他私密内容。
